Accessibility Statement

1. General Principles and Commitment

Valeriy Kuvshinov, operating as Kuvshinov Software ("I" or "the Company"), is an independent software developer and accessibility consultant. Because I fix accessibility problems for clients, I hold this website to the same standard. My goal is for every visitor, including people with visual, motor, or cognitive disabilities, to be able to use it equally and without barriers.

This statement applies to the website at kuvware.com. The business is run remotely and has no physical office open to the public, so physical access does not apply.

2. Digital Accessibility Standards

This website is built with native, semantic code, to meet Israeli Standard IS 5568 at Level AA and the W3C Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA. It also meets several Level AAA criteria, such as enhanced color contrast.

I do not rely on automated accessibility overlays or temporary widget patches. Accessibility is built into the code itself, to work with assistive technologies such as screen readers, braille displays, and alternative input devices. The accessibility menu on this site is an optional set of display preferences on top of that foundation, not a replacement for it.

I test this site with the NVDA screen reader and with automated tools (Lighthouse and axe DevTools). Automated tools catch only part of the possible issues, so some barriers may still exist. If you find one, please tell me.

3. Accessibility Features

This site includes the following accessibility features, plus an accessibility menu that lets you adjust the display:

  • Clear page structure: Headings follow a logical order (H1 to H6), ARIA labels are used where needed, and page regions (<main>, <nav>, <aside>) help screen reader users move around quickly.
  • Full keyboard use: Everything can be operated with a keyboard, with clearly visible focus indicators, and focus stays inside dialogs while they are open.
  • Skip links: Skip links at the top of each page let keyboard users jump straight to the main content or the footer.
  • Color contrast: Text and interactive elements meet or exceed the enhanced AAA contrast ratio (7:1).
  • Display preferences: The accessibility menu lets you change the font (including a dyslexia-friendly option), text size, line spacing, and letter spacing.
  • Reduced motion: You can pause animations from the accessibility menu, and the site also follows your device's reduced-motion setting (prefers-reduced-motion).

4. Known Limitations and Third-Party Content

Some parts of your experience depend on services I do not control:

  • Security checks (CAPTCHA): To prevent automated abuse, this site uses Cloudflare Turnstile, which usually runs invisibly. Strict browser privacy settings may occasionally trigger a visual challenge. If that blocks you, contact me by phone or email and I will help.
  • Third-party content and links: The site embeds a YouTube video and links to external sites such as LinkedIn, GitHub, Fiverr, Facebook, and client portfolio sites. These are run by other organizations, so their accessibility is outside my control.

5. Feedback and Contact

I review this site regularly and fix accessibility problems as I find them. If you meet a barrier, find an error, or need information in another format, please tell me through the contact page, or contact me directly by email ( contact@kuvware.com ).

I respond to accessibility inquiries within 2 business days and prioritize fixing the barrier.
